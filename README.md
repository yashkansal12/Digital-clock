# ⏰ Digital Clock

A simple and elegant digital clock built using **HTML, CSS, and JavaScript**. It displays the current time in real-time and updates every second.

## 🚀 Features

- Real-time digital clock display
- Displays hours, minutes, and seconds
- 12-hour / 24-hour format support (update as per your implementation)
- Clean and responsive UI
- Built with vanilla JavaScript — no external libraries

## 🛠️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling
- **JavaScript** – Logic (using `Date` object and `setInterval`)
